AMX Visualizer — coming soon

The local visualizer backend is running. The polished SPA bundle ships in PR-B; until then this page is the placeholder.

You can still hit the JSON API directly:

  • GET /api/health
  • GET /api/version
  • GET /api/context

Every /api/* request needs the bearer token from the URL ?t=… parameter — drop it into Authorization: Bearer <token>.

Press Ctrl-C in the parent terminal to stop the visualizer.
